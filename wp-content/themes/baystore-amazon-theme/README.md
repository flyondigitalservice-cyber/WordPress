# Baystore Amazon Lean — WordPress + WooCommerce Theme

A complete, high-converting WordPress + WooCommerce theme tailored for **Baystore.in**, combining **Amazon UI & UX** with the **Lean Method of Conversion**.

## Quick Installation (5 Minutes)

1. **Upload & Activate Theme**
   - In WordPress Admin, go to **Appearance → Themes → Add New → Upload Theme**.
   - Upload `baystore-amazon-theme.zip` and click **Activate**.
2. **Install & Activate WooCommerce**
   - Go to **Plugins → Add New**, search for **WooCommerce**, install and activate it.
   - Set Currency to **Indian Rupee (₹)** under **WooCommerce → Settings**.
3. **1-Click Import All 90 Baystore.in Products & `BAY10` Coupon**
   - Go to **Appearance → Baystore Importer**.
   - Choose how many products to import (20, 45, or all 90) and click **Import Baystore Catalog & Create BAY10 Coupon**.
4. **Customize Thresholds & Copy**
   - Go to **Appearance → Customize → Baystore Lean Conversion Settings** to edit the Free Delivery threshold (`₹499`), coupon code (`BAY10`), and Hero headlines.

## Included Amazon UI & Lean CRO Features
- **Sticky Amazon Header**: Dark-navy `#131921` header, custom `baystore.in` SVG logo, interactive Indian **Pincode Delivery ETA Modal**, department-scoped **AJAX Live Search Autocomplete**, and `#232F3E` department bar + slide-out **All** mega-menu.
- **Floating 4-Card Amazon Bento Grid + 3-Slide Hero Carousel**: Highlights Home & Kitchen, Auréveda Superfoods, Smart Gadgets, and a 1-tap `BAY10` Deal Box.
- **AJAX Slide-Over Cart Drawer**: Live **₹499 Free Delivery Progress Bar**, `+ / -` quantity controls, 1-click `BAY10` coupon apply, and direct Checkout button.
- **3-Column Amazon Single Product Page**: Gallery, Available Offers box, bulleted specs, and sticky right **Buy Box** with Pincode ETA, **Add to Cart** (`#FFD814`), and 1-click **Buy Now** (`?baystore_buy_now=ID` straight to checkout).
- **Lean Checkout Optimization**: Sticky 2-column checkout summary and automatic removal of friction fields (`billing_company`). Works natively with Indian UPI / Razorpay / PhonePe / Cashfree / COD WooCommerce gateways.
