=== Posh Banner Slider ===
Stable tag: 1.0.0
License: GPLv2 or later

Auto-sliding hero banners for a premium laptop store.

== Usage ==
1. Activate the plugin (Plugins → Posh Banner Slider).
2. Add the shortcode [posh_banner_slider] to any page/block (Shortcode block), or call
   <?php echo posh_banner_slider(); ?> in a theme template.
3. Appearance → Banner Slider: set the auto-slide speed, edit text/links, and
   "Choose image" for each slide to replace the placeholder with your generated banner.

Recommended image size: 1920×700 px (WebP/JPG). Leave the image empty to show the
built-in 3D text placeholder (5 styles: Fire, Gold Luxury, Neon Gaming, Royal, Mint).

Features: auto-play with progress bars, pause on hover/focus/tab hidden, arrows, dots,
swipe on mobile, keyboard arrows, Ken Burns zoom on images, reduced-motion support.
