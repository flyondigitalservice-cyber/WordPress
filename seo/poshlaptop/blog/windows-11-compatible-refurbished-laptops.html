Windows 10 support has ended, so if you are buying a refurbished laptop today it makes sense to choose one that can run Windows 11 and keep getting security updates. The good news is that most business laptops from 2018 onwards qualify. Here is how to tell whether a refurbished laptop is Windows 11 compatible.

Microsoft's main requirements

Check Microsoft's PC Health Check app or its list of supported processors if you are unsure about a specific model.

How to read a laptop listing

Look at the processor model number. In Intel names, the first digit or two after the dash show the generation:

  • i5-6200U = 6th Gen: not officially supported
  • i5-7300U = 7th Gen: not officially supported (with very few exceptions)
  • i5-8365U = 8th Gen: supported
  • i7-1165G7 = 11th Gen: supported
  • i7-1255U = 12th Gen: supported

Frequently asked questions

Can a refurbished laptop run Windows 11?

Yes, if it has a supported processor (generally Intel 8th Gen or newer, or AMD Ryzen 2000 series or newer), TPM 2.0 and Secure Boot. Most business laptops from 2018 onwards qualify.

Does an Intel 7th Gen laptop support Windows 11?

Generally no. Apart from a very small number of exceptions, Intel 7th Gen processors are not on Microsoft's supported list.

How do I check if my laptop is Windows 11 compatible?

Run Microsoft's PC Health Check app, or check the processor model against Microsoft's list of supported processors.
