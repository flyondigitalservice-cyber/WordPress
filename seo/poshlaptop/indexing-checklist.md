# Posh Laptop: Google indexing checklist

Google only lets the site owner request indexing, inside Search Console. Each URL takes about 30 seconds.
Google limits this to roughly 10–12 requests per day per property, so do the first batch today and the rest tomorrow.

## Step 1: Submit the sitemap (once)
Search Console → **Sitemaps** → enter `sitemap_index.xml` → **Submit**.
If it's already listed, click it and check that **post-sitemap.xml** now appears with 6 URLs.

## What to expect
- "URL is not on Google" before requesting is normal for new pages.
- Indexing usually takes from a few days to two weeks. Check again with URL Inspection after a week.
- If a page shows "Crawled – currently not indexed" after 2–3 weeks, tell Claude: the fix is usually more
  internal links or more unique content on that page.
